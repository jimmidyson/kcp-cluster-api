Documentation for kcp-cluster-api is split into two audiences:

- **[User docs](user/_index.md)** — installation and usage. Start here if you
  want to run kcp-cluster-api.
- **[Design & architecture](design/_index.md)** — technical reference for
  developers and agents (human or AI) working on this codebase. Start here
  if you want to understand or change how it's built.

See [Documentation policy](design/documentation-policy.md) for what's
expected of new docs when the codebase changes.
