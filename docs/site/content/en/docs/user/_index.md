Installation and usage information for people running kcp-cluster-api. If
you're looking for how the project is built rather than how to run it, see
[Design & architecture](../design/_index.md).

New here? [The demo, deployed](kubernetes.md) is one command — a kind cluster,
a kcp shard and every provider as pods — and
[the walkthrough](walkthrough.md) takes the same run apart piece by piece
without assuming you know kcp. [The demo in one process](demo.md) is the same
thing in about a minute with no container runtime, for when the question is
whether something still works rather than whether it works deployed.

Getting a workspace of your own, and turning on the providers you want, is
[Onboarding a workspace](onboarding.md).
